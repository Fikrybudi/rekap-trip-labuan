Catatan metodologi

1. Titik proteksi: REC=PMR, SEC=SSO; nama segmen diseragamkan (typo spasi/huruf, mis. PMR DADAP LANGU = PMR DADAPLANGU).
2. Baris ganda: 150 baris identik di Sheet10 (2026) — Jan 1, Feb 38, Mar 46, Apr 21, Mei 28, Jun 16; Jul–Okt bersih. Semua kartu memakai data bersih.
3. Oktober disajikan mingguan + harian: M1 = 1–4 Okt (8 trip); cut-off data 11 Oct 2026.
4. Filter Bulan mempersempit tabel rekap, Top segmen, pie chart, dan KPI; kolom harian hanya untuk tahun 2026.
5. Penyulang CIGONDANG di canvas ini = gabungan CIGONDANG + PAGELARAN (sesuai permintaan).
5b. Penyulang MANDALAWANGI dikecualikan (milik ULP Pandeglang, bukan Labuan).
5c. Nama titik proteksi dirapikan: varian typo disatukan → SSO CICECUNING→CICEUNING · CBO GH TARONGGONG OUT SUMUR→TAROGONG OUT SUMUR · CBO GH TARONGGONG OUT CIBALIUNG→TAROGONG OUT CIBALIUNG · SSO PASIRJIPUT→PASARJIPUT · PMR TENJOHALANG→TENJOLAHANG · PMR CISEKEUT→CISEUKEUT · PMT CIBALIUNG GH TAROGONG→CBO CIBALIUNG GH TAROGONG · PMR KALICAAAH→KALICAAH.
6. Auto-update: file ini snapshot yang di-rebuild otomatis oleh refresh_canvas.py — menarik ulang Sheet10 dari MIRROR KINERJA LABUAN, lalu membangun ulang HTML ini (jadwal Windows Task Scheduler “RefreshCanvasTripLabuan”, tiap 30 menit). Manual: klik REFRESH_CANVAS.bat.
7. Angka rekapan atas (34/104/96/85/64/69/50/43/68/8) tidak bisa direproduksi dari Sheet10 — kemungkinan dari laporan harian DCC/WhatsApp atau hitungan manual.
